# Библиотека LayoutSigns для Arduino
LayoutSigns предназначен для обработки данных с пульта управления макета железнодорожной станции для последующего построения маршрута на светофорах.

Библиотека решает следующие задачи:
* Получения состояний стрелочных переводов (требуется привод с постоянной индикацией положения стрелки);
* Установить логический уровень отключенного сигнала светофора (по умолчанию = 1);
* Составить соотвествие между контактами Arduino или контактами PCF-модуля* с номером сигнала на светофоре;
* Управление сигналами светофора;
* Задать период мерцания для мигающих сигналов;
* Автоматическое управление мигающими сигналами (включение / отключение мигания);
* Задать состояния светофора по умолчанию;
* Получить состояние светофора по умолчанию;
* Перейти к состоянию по умолчанию для светофора;
* Автоматическая обработка состояния всех светофоров на станции.

\* PCF8574 - микросхема преобразования цифровых данных I2C <-> Parallel; PCF8575 - тоже самое, но аналоговых.

## Библиотеки-зависимости
1. [Adafruit_BusIO-master](https://github.com/adafruit/Adafruit_BusIO)
2. [Adafruit_PCF8574](https://github.com/adafruit/Adafruit_PCF8574)

## Начало работы
Сначала добавьте библиотеку в вашу папку `libraries`, добавьте зависимости и импортируйте:
```c
#include "Adafruit_PCF8574.h"
#include "LayoutSigns.h"
```

## Создание светофора и задание состояния по умолчанию
Создать экземпляр класса `Svetofor` можно как с указанием типа контактов, так и без - в таком случае pcf_mode = false. При этом допустим либо режим, когда все контакты Ардуино, либо, когда все контакты - PCF.
```c
#include "Adafruit_PCF8574.h"
#include "LayoutSigns.h"

Svetofor svet;  // Создаем объект с глобальным доступом
Svetofor svet2;

Adafruit_PCF8574 pcf;  // Создаем объект обработчика PCF-модуля

void setup(){
    svet = Svetofor();  // Создаем экземпляр класса
    // Устанавливаем соотвествие огонь светофора <-> контакт Ардуино
    svet.set_ard_pin(0, 2);
    svet.set_ard_pin(1, 3);

    /*
     *   Cоздаем экземпляр класса с указанием _pcf_mode
     *   _pcf_mode = true => ВСЕ огни светофора подключены через модуль PCF8574
    */
    svet2 = Svetofor(true);
    
    pcf.begin(0x20, &Wire);  // Установка адреса для PCF
    
    /*
     *   Устанавливаем соотвествие PCF-модуль, номер контакта на PCF-модуле 
     *   <-> огонь светофора
    */
    svet2.set_pcf_pin(0, &pcf, 0);
    sve2t.set_pcf_pin(0, &pcf, 1);
}
```
Модельный светофоры имеют общий плюс питания и разрыв земли для каждого светодиода. Соотвественно, по умолчанию параметр `light_off_value = 1`, что соотвествует положительному потенциалу на катоде светодиода. Если требуется иной режим работы, то можно изменить это значения:
```c
...
svet = Svetofor();
// Устанавливаем отрицательный потенциал на катоде светодиодов
svet1.set_light_off_value(0);

svet1.set_pcf_pin(0, &pcf, 0);
svet1.set_pcf_pin(0, &pcf, 1);
...
```
Устанавливать потенциал по умолчанию требуется **до назначения контактов**, так как это значение будет использовано при назначении.

## Цикл работы
Библиотека реализует клиент-серверный подход к выполнению задач, то есть требуется создать некоторый пулл запросов, и далее `LayoutSigns` самостоятельно пройдется по всему набору запросов и выполнит их. Такой подход хорош тем, что весь бэкенд скрыт за единым методом `work()`, а вам достаточно посылать запросы на изменение состояния светофора.

Важные особенности:
* Назначение контактов создает запрос автоматически;
* Метод `work` должен вызываться каждый такт;
* Запрос достаточно послать единожды, состояние огня может изменится при следующем запросе, отложенном во времени;
* Метод `get_default` самостоятельно создает запрос.


## Управление огнями светофора
Для того, чтобы задать постоянное состояние огня светофора требуется применить метод `set`.
```c
#include "Adafruit_PCF8574.h"
#include "LayoutSigns.h"

Svetofor svet;

Adafruit_PCF8574 pcf;

void setup(){
    pinMode(2, INPUT_PULLUP);
    
    svet = Svetofor(true);
    pcf.begin(0x20, &Wire);
    
    svet.set_pcf_pin(0, &pcf, 0);
    svet.set_pcf_pin(0, &pcf, 1);

    // Задаем состояние огня под номером 0 -> ВКЛ.
    svet.set(0, LOW);
}
void loop(){
    // Нажата ли кнопка?
    if (digitalRead(2) == 0){
        svet.set(1, LOW);  // Огонь 1 -> ВКЛ.
    }
    else{
        svet.set(1, HIGH);  // Огонь 1 -> ОТКЛ.
    }
    
    /*
     * ...
     * Остальная логика
     * ...
     */

    // Вызов бэкенда
    svet.work();
}
```
Обратите внимание что огонь `0` остается включеным все время, когда огонь `1` загорается только по нажатию кнопки. Бэкенд в первом такте выполняет запрос на включение огня `0` и удерживает его в этом состоянии до следующего запроса, который уже не поступит.

## Получить состояние огня
Если же требуется наоборот получить состояние огня (постоянное), то есть влючен или выкллючен он, то можно воспользоваться `is_light`, к примеру так:
```c
...
if (svet.is_light(0)){
    // Дествие
}
...
```
Где в скобках указывается едиственный параметр - номер огня. **Важно обратить внимание** на то, что данная функцию будет коректно отрабатывать только при условии, если состояние огня фиксированно, то есть он не мигает.

Это связано с невозможностью прочитать данные с контакта, назначенного на вывод. Состояния хранится в програмной логике отдельно для фиксированных и мигающих состояний.


## Управление состоянием по умолчанию
`save_as_default()` - сохраняет текущие состояние светофора, как состояние по умолчанию для него.

`get_default()` - переводит светофор в состояние по умолчанию, учтите, что сбрасывается в том числе мигающий сигнал.


## Мигающие огни
### Управление и чтение состояния
`svet.blink_on(uint8_t signal)` - переводит огонь номер **signal** в мигающее состояние.

`svet.blink_off(uint8_t signal)` - огонь номер **signal** перестает мигать.

`is_blink(uint8_t signal)` - получаем статус мигания от огня номер **signal**.

Рассмотрим следующий пример.
```c
...
void loop(){
    if (digitalRead(2) == 0 && !svet.is_blink(1)){
        svet.blink_on(1);  // Огонь 1 -> НАЧИНАЕТ МИГАТЬ
    }
    else{
        svet.blink_off(1);  // Огонь 1 -> ПЕРЕСТАЕТ МИГАТЬ
    }

    svet.work();
}
...
```
В данном случае проверка `!svet.is_blink(1)` хоть и избыточна, но показывает пример применения данного метода.

### Задать период мигания
Пусть `f` - частота мигания, тогда
```
t = 1/f
```

На вход метода требуется передавать значение в **милисекундах**.

```c
svet.set_blink_delay(uint16_t t);
```
